Project Details

Project Start Date: January 2020

Project End Date: March 2020

Project Duration: 3 months

Project Team Size: 2 members

  • Integrated Barometer, Accelerometer, Gyroscope, and Temperature sensors for comprehensive environmental data collection.
  • Designed and constructed a miniature parachute system to facilitate controlled descent, enabling data gathering during descent.
  • Established wireless communication between emitter and receiver units for real-time data transmission.
  • Implemented data processing techniques including data smoothing and graphical representation for analysis.
