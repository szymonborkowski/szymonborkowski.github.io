Project Details

Project Start Date: October 2022

Project End Date: December 2022

Project Duration: 3 months

Project Team Size: Solo project

  • Implemented a state machine using basic logic gates and flip flops to iterate through a programmed sequence, manually clocked and verified by LED indication.
  • Enhanced the system by integrating an Arduino for automated sequence feeding, clocking, and output reading.
  • Developed a GUI using the Processing IDE, facilitating interactive control for inputting bits, clocking circuits, and verifying sequence accuracy.
